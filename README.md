##  Project Overview
This project is a responsive website for Honey Bears Bakery — a family-run bakery based in Randburg, Johannesburg. The website provides customers with business information, product listings, an interactive image gallery, search functionality, enquiry forms, and location details. This website was developed as the Final POE for the Web Development module.

##  Technologies Used
| Technology | Purpose |
|---|---|
| **HTML5** | Page structure, content, and semantic markup |
| **CSS3** | Styling, layout, colour scheme, and responsive design |
| **JavaScript** | Search filtering, image lightbox, and form validation |
| **Google Maps Embed** | Interactive location map |

##  Features Implemented

###  Pages & Navigation
- 5 complete, linked HTML pages
- Consistent navigation menu across all pages
- Active page highlighting in navigation
- Footer displayed on every page

###  SEO & Meta Tags
- Unique `<title>` tag on each page
- Meta `<description>` on each page (150–160 characters)
- Meta `<keywords>` relevant to each page

###  Images & Accessibility
- All images include descriptive `alt` text
- `loading="lazy"` attribute applied for faster page loading

###  Dynamic Search / Filter
- Search bar on Our Services page
- Instantly filters products as user types
- No page reload required
- Case-insensitive search

###  Image Gallery with Lightbox
- Grid gallery on Our Services page
- Click any thumbnail to open enlarged view (lightbox)
- Close options: Close button, click outside image, or Escape key
- Smooth transitions and hover effects

###  Enquiry Form
- Fields: Full Name, Email, Phone Number, Enquiry Type, Message
- Required field validation
- Email format validation
- Success message displayed on valid submission
- Error messages for missing/invalid data
- Form resets after successful submission

###  Contact Form
- Fields: Name, Email, Subject dropdown, Message
- Required field validation
- Email format validation
- Success confirmation message
- Error messages displayed clearly

###  Embedded Google Map
- Interactive map embedded on Contact page
- Location: 56 Willow Street, Randburg, Johannesburg
- Fully responsive — fits different screen sizes
- Lazy loading enabled

###  Responsive Design
- Desktop view (1024px+)
- Tablet view (768px – 1023px)
- Mobile view (under 768px)
- Flexible layouts and readable text on all devices
